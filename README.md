# The Architect's Lament

A narrative-driven game exploring morality through 4 interconnected realities.

## Features
- 4 distinct acts (Sci-Fi, Fantasy, Horror, Realism)
- Moral choice tracking system
- Branching narrative with consequences
- Typewriter dialogue effects
- Local save system
- Event-based architecture

## Development Stats
- Target: 10,000+ lines of code
- Target: 150+ Git commits
- Development time: 1 month
- Technologies: HTML5, CSS3, JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` in a browser
3. Click "BEGIN EXPERIMENT" to start
